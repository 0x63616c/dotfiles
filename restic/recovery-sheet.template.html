Restoring

brew install restic          # or: apt install restic

export RESTIC_REPOSITORY='{{REPO_URL}}'
restic snapshots                          # prompts for either password above

# browse before committing to anything
restic mount /tmp/backup                  # snapshots appear as normal folders

# or restore outright
restic restore latest --target /tmp/restore
restic restore latest --target /tmp/restore --include /Users/calum/Documents

What is NOT in this backup

  • Photos. iCloud Photos held the originals; the Mac only had thumbnails. Recover from iCloud.
  • Caches, package stores, git worktrees, VM images — all rebuildable.
  • No bare-metal restore. This is files, not a bootable system.
